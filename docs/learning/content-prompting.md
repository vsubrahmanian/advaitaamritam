## How to prompt

ROLE
↓
TASK
↓
CONTEXT
↓
CONSTRAINTS
↓
OUTPUT FORMAT

### Define 
ROLE:
You are an Advaita Vedanta content editor.

TASK:
Create one Daily Jewel.

CONTEXT:
The audience is sincere seekers, including people unfamiliar
with technical Sanskrit terminology.

CONSTRAINTS:
Never invent Sanskrit or attribution.
Use only the supplied source.
Keep the reflection contemplative, not motivational.

OUTPUT:
Return source, original, translation, reflection,
contemplation and image prompt.

### Example
Brand:
Advaitaamritam

Audience:
Sincere seekers

Tone:
Calm, contemplative, timeless

Avoid:
Generic motivational language

Source:
Bhagavad Gita 2.20
